# Garage asset attribution

All Poly Haven downloads below are CC0. Retrieved 2026-09-19 through the public Poly Haven asset file API, saved locally and served with the game (no runtime third-party requests).

- Industrial Workshop Foundry HDRI — Dimitrios Savva (photography), Jarod Guest (processing): https://polyhaven.com/a/industrial_workshop_foundry
  - `workshop.hdr`, original 2K Radiance HDR, 6,636,267 bytes.
- Concrete Floor: https://polyhaven.com/a/concrete_floor
  - `concrete_floor-Diffuse.webp`, `concrete_floor-nor_gl.webp`, `concrete_floor-Rough.webp`.
- Concrete — Rob Tuytel: https://polyhaven.com/a/concrete
  - `concrete-Diffuse.webp`, `concrete-nor_gl.webp`, `concrete-Rough.webp`.

All six material images retain 2048 x 2048 pixels. WebP quality 88 for diffuse/roughness, 94 for normal maps; original downloaded JPEG masters are retained locally and excluded from the Sandscape bundle.

OrbitControls and RGBELoader are vendored from Three.js 0.160.0, matching the existing engine revision, under Three.js's MIT license.
